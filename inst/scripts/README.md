# How the package data were built

Every object in `data/` is rebuilt by one script in this folder, which ships with the package so that the provenance of each number can be checked. Each script writes `sessioninfo/<script>.txt` with the date, the package versions and, where it applies, the commit of the analysis repository.

- `build_signatures.R` writes `data/thanatome_signatures.rda`: the consensus signatures of the death axes. Source: the per-tissue DESeq2 consensus tables of the analysis repository `hachepunto/thanatome-manuscript` (`results/firmas/{ventilador,isquemia,agonia}_consenso.tsv`; GTEx v8 gene read counts from the GTEx portal, ten tissues, Stouffer consensus across tissues). The tables will be deposited in Zenodo with the manuscript; until then the script reads them from a local checkout given in the environment variable `GTEX_CONTROLS`. Thresholds: concordant sign in at least 5 of 10 tissues and |median log2 fold change| > 0.5 for the ventilator and agony axes, > 0.25 for the ischemia component (its contrast is per standard deviation of ischemic time).
- `build_references.R` writes `data/thanatome_references.rda`: per tissue, mean and standard deviation of log2-CPM of the signature genes across the GTEx v8 samples of that tissue, which genes are expressed there, and the poles of each axis. Source: recount3 (Wilks et al. 2021), GTEx projects OVARY, BREAST, THYROID, LUNG, COLON, LIVER, PROSTATE, UTERUS and SKIN, `recount3::create_rse(type = "gene", annotation = "gencode_v26")` followed by `compute_read_counts()`, RNASEQ freeze samples, one run per sample. The script downloads them with recount3 unless `THANATOME_RECOUNT3_DIR` points to a folder with cached `<PROJECT>_gtex.rds` files. The packaged references therefore match data quantified with the recount3 Monorail pipeline (GENCODE v26); cohorts quantified otherwise should use a cohort reference (see `?thanatome_score`).
- `build_example.R` writes `data/thanatome_example.rda`: 74 GTEx v8 ovary samples and 40 TCGA-OV primary tumours from recount3 (projects OVARY and OV), restricted to the signature and flag genes, with the full library size of each sample in `colData`.
- `record_session.R`: helper used by the three scripts.
